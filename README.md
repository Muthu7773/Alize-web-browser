# Alize Web Browser

## Overview

Alize Web Browser is a secure Android browser developed as my Final Year B.E. Computer Science Project.

The objective of this project is to improve safe web browsing using multiple security features including phishing detection, malware download scanning and encrypted password storage.

---

## Features

- Secure Android Browser
- URL Threat Detection
- HTTPS Enforcement
- Malware Download Scanning
- AES-256 Password Vault
- Privacy Protection
- Simple User Interface

---

## Technologies

- Flutter
- Java
- Android SDK
- Firebase
- AES-256 Encryption
